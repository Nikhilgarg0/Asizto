## 2025-05-14 - Search Input Accessibility and UX
**Learning:** Adding a 'Clear' button to searchable inputs improves user experience by providing a quick way to reset state, especially on mobile. Ensuring interactive elements have ARIA roles and labels is critical for screen reader support.
**Action:** Use the established `searchInputWrapper` pattern with an inline `Ionicons` "close-circle" button for all future searchable inputs.
