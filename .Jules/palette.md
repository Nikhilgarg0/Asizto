## 2025-05-14 - Actionable Feedback over Silent Disabling
**Learning:** Prefer showing an actionable Alert upon click over disabling buttons (like search or submit) without context. This helps users understand validation requirements immediately rather than leaving them wondering why a button is unresponsive.
**Action:** When a button has validation requirements (e.g., minimum character length), keep the button enabled and provide clear feedback via an Alert or inline message if the requirement is not met.
