# Palette's Journal - Critical UX Learnings

This journal tracks critical UX and accessibility insights discovered during development.

## 2025-05-14 - [Initial Setup]
**Learning:** Initialized Palette's journal for the Asizto project.
**Action:** Ready to implement UX improvements.

## 2025-05-14 - [Search Usability & Accessibility]
**Learning:** Inconsistent search patterns (missing clear buttons) and lack of accessibility labels on interactive elements can hinder both power users and those using assistive technologies.
**Action:** Implemented a "Clear Search" button in the Dashboard's medicine search that resets both the input and results, and added proper ARIA-equivalent labels to improve screen reader support.
